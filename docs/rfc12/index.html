From hardware diagrams to a useful invariant

M. Wingfield's RFC 12 (26 August 1969) documents IMP–HOST hardware sequences extracted from BBN Report 1822. Its RFC Editor status is Unknown, with no update or obsoleting relationships listed when checked on 5 November 2026. This word-level ready/valid model is an educational adaptation; it does not reproduce the historical bit signals, padding, timing or electrical interface.
