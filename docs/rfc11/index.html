INTERNET RFC SERIES / 011

A connection has a lifecycle.

Explore a Go-generated trace: reserve → acknowledge → route → drain → close. Expand any step to inspect all active connections and their bounded inboxes.

Inspired by G. Deloche's August 1969 GORDO design. RFC 11 has status Unknown and is obsoleted by RFC 33. This is an educational model with modern generation IDs and explicit backpressure, not historical protocol compliance or a banking service.

This static viewer contains saved output from Go. It does not run a server or execute Go in your browser. To change the scenario, edit examples/sessions.json and regenerate with the command in the README.
